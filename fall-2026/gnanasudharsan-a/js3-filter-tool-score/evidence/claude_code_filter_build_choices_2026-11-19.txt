## Choices FILTER.md does not decide

**Matching**
1. **What counts as a word boundary.** No letter or digit may come directly before or after a match, and phrases allow any amount of whitespace between their words. So punctuation and hyphens are boundaries: "sr" matches "Sr.", and "transformers" also matches inside "sentence-transformers". That one text then counts once in B2 and twice in B3.
2. **No plurals or variants.** "LLMs", "embedding", "fine tuning" (no hyphen) and "US citizenship required" (no dots) do not match.
3. **HTML handling.** I unescape, strip tags, then unescape and strip again, because escaped HTML can hold escaped entities. Then I collapse whitespace and lowercase. Departments are never read.
4. **Which fields each rule reads.** A1 and B1 read the title. B2 and B3 read the content. A3–A7 say "Text", and I read that as title + content.

**Stage A**

5. **What counts as US for A2.** I split the location on `|` and `;`. A posting passes if any part contains the whole word "remote", or one of "united states" / "usa" / "us" / "u.s." / "u.s.a.", or ends in ", <state code or full state name>" (DC included).
   - So "Remote – London" passes, because the rule says "nor remote" without limiting it to the US.
   - A US city with no state ("San Francisco", "Boston") is rejected, because the location is known but not recognized.
6. **A3 phrase list.** I took the quoted examples as the complete list. JS1's "not currently able to sponsor" is not in it, so it does not reject. A3 fired 0 times.
7. **A4 pattern.** Only "N+ year(s)" with N ≥ 3 counts, whatever follows ("5+ years of Python" fires). "At least 3 years", "minimum of 5 years" and "3 or more years" don't fire.
8. **A5 phrasing.** It fires on "PhD/Ph.D. (degree) (is) required" and "require(s) a PhD". It does not fire when "required" appears later in the sentence.
9. **A6 and A7 are literal.** "No security clearance needed" would fire A6, and a benefit like "volunteer time off" would fire A7. In this run A6 fired 21 times and A7 fired 0 times. I didn't check whether the 21 are real clearance requirements.

**Abstention and scoring**

10. **A missing title is treated as empty.** It can't trigger A1 or B1, and the posting is not sent to cannot_tell, since FILTER.md only lists location and content for abstention.
11. **Only (a) and (b) of the abstention rule are implemented.** Part (c), "level claim insufficient and no title level signal", is about justification claims, so it's not in the filter.
12. **Order of checks.** Stage A runs even when location or content is missing, which is why a seniority reject wins over a missing location.
13. **Score is `None` when a posting is rejected by Stage A or is cannot_tell.** Components are still computed for every posting so the audit can see them.
14. **Components keep the full list.** `components.B2` and `B3` list every distinct match in FILTER_V1 order; the caps only limit the points.
15. **What `matched` holds.** It has the matched text for each Stage A rule that fired. For A2 that is the whole location string. For A4 it is the first "N+ years" with N ≥ 3. It also includes B1's phrase when the title matches.

**The runner**

16. **Which body it reads.** It maps boards to files through `boards.json` and uses the latest `attemptN.body` for each board. It parses with `jobwatch.loop._parse_jobs` (imported, not edited). A board with no posting list is printed as EXCLUDED, never counted as 0.
17. **It won't overwrite.** If `filter_v1.jsonl` already exists the script refuses to write, so a second run needs that file moved first.
