## How to rebuild

Free and local: no API keys, no paid generation, no upload. Full steps are in `BUILD-PROMPT.md`. Short version:

```bash
# toolkit beside this folder, at commit 519fcbb, venv active (Python 3.11, Manim 0.20.x)
(cd first-run && ./run_all.sh && ./score_round.sh 1 && ./score_round.sh 2)   # the film typesets results/2026-10-25/
cd film-v3
python make_sheet.py
python ../../Brutalist/runtime/scripts/generate_audio_kokoro.py . && python finish_audio.py
./build_scenes.sh
cd ../../Brutalist && ./art run ../Final_Project_Pitch/film-v3 && ./art final ../Final_Project_Pitch/film-v3 --out ../Final_Project_Pitch/film-v3/exports
cd ../Final_Project_Pitch/film-v3
python ../../Brutalist/runtime/scripts/align.py . && python make_captions.py   # subtitles; then mux (BUILD-PROMPT.md §3)
```
