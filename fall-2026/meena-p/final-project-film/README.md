## How to rebuild the film

The full command sequence, with environment notes, is in **`BUILD-PROMPT.md`**. In short:

1. **Toolkit.** Clone the Brutalist toolkit (`https://github.com/nikbearbrown/brutalist.art`). This film was built with a fork checkout at commit `5a00f54`. Run `./setup --install`, then use its `.venv` (Python 3.12). At that commit the toolkit pins `manim>=0.20,<0.21`; the film was rendered with Manim Community 0.20.1.
2. **Sheet.** `python3 make_sheet.py` writes `beat_sheet.json`.
3. **Narration.** `python3 <toolkit>/runtime/scripts/generate_audio_kokoro.py <this folder>`, then `python3 finish_audio.py` to pad the bookends and measure.
4. **Review cut.** `<toolkit>/art run <this folder> --height 2160`
5. **Final.** `<toolkit>/art final <this folder> --out <this folder>`
6. **Gates.** Run every gate listed in `BUILD-PROMPT.md`, and the render-integrity check.

Everything runs locally and free: Kokoro narration, Manim and Remotion rendering, ffmpeg. No API key is needed to build the film.
