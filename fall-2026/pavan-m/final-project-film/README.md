## What this is

A pitch, not a build. The film describes a planned final project: a command-line tool that reads logs from a failing backend service, proposes a root cause, and cites the exact log lines that support it, or says the evidence isn't enough. **Nothing in the project exists yet.** Every drawing in the film carries an on-screen "constructed sketch" tag, the results table shows no numbers, and everything planned is narrated in "will." See `PROJECT-BRIEF.md` for the seven answers and the exists / will-exist lists.

## How to rebuild

Short version below; full commands in `BUILD-PROMPT.md`.

1. Clone the Brutalist toolkit and install it in a Python 3.12 environment (Manim 0.18 does not support Python 3.13+).
2. Apply `src/outro-handle.patch` to the toolkit, so the outro shows my name instead of the toolkit's hard-coded instructor handle.
3. In the reel folder: run `make_sheet.py`, generate the Kokoro audio locally, pad the outro, build `scenes.py`, then `art run` and `art final`.

Everything runs locally and free: Kokoro voice, Manim and Remotion rendering. No API keys, no paid generation, no upload.
