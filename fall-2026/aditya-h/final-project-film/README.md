**ProductLens AI** will help a product manager decide whether to build a feature, and what to test first. You describe the
feature and attach a few public articles; it returns a one-page decision brief (risks, metrics, first experiment) with
every claim labelled as sourced or assumption, and code checking the quotes against the sources.
This is a **pitch, not a build**: nothing in ProductLens exists yet except the idea, the outlines, and the chatbot tests in
`research/`. Each part of the film has a bottom subheader saying what it's about. On drawings of the unbuilt product it ends
**"· concept sketch"**. My own Oct 25 test is shown as real screenshots.
