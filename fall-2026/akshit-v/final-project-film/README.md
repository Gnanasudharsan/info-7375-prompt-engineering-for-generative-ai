## The pitch in one sentence

SponsorScout will be a Claude Code workflow that tells an international student looking for data
jobs, company by company, whether to **apply, network, check by hand, or skip**, and cites the
public record behind every verdict. A prototype already runs (Assignment 1, run-2, 2026-10-03).
The seven answers are in `PROJECT-BRIEF.md`.

## What exists vs. what is proposed

The film tags every drawing on screen: `constructed drawing · ran <date>` or
`constructed drawing · proposed`. The title beat shows the legend. "Exists today" and "will exist"
are listed at the end of `PROJECT-BRIEF.md`.

## Rebuild the film

Full detail is in `BUILD-PROMPT.md`. Short version (free and local):

```bash
git clone https://github.com/nikbearbrown/brutalist.art && cd brutalist.art
git checkout 6a8380ae169cca81e0633664a65c958f5c12ab4b
./setup --install
# apply the toolkit changes: see toolkit-changes/README.md (three commands)
# put this folder at youtube/brutalist/final-project-film/
export PYTHONUTF8=1 PYTHONIOENCODING=utf-8 ART_CHANNEL_TITLE=0
REEL=youtube/brutalist/final-project-film
python $REEL/make_sheet.py
python runtime/scripts/generate_audio_kokoro.py $REEL
python runtime/scripts/align.py $REEL
python runtime/scripts/remotion_scenes.py $REEL
ART_BURNIN=0 ART_QC=1 ART_STRICT=1 bash runtime/scripts/run.sh $REEL --height 1080
./art final $REEL --height 1080
cp renders/sponsorscout-final-project-pitch.mp4 $REEL/sponsorscout-final-project-pitch-nocaptions.mp4
cd $REEL && python tools/make_captions.py   # then burn in: BUILD-PROMPT.md §5
```
