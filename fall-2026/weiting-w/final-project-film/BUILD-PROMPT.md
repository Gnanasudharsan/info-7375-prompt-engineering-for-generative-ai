# BUILD-PROMPT — the-names-nothing-checks

Everything needed to rebuild this film from an empty folder. Commands are macOS; the toolkit
runs the same on Linux. Nothing here costs money and nothing needs an API key.

Two folders, kept apart on purpose:

- **the toolkit** — a clone of `brutalist.art`. Thirteen thousand files. It is *not* committed
  into the course repository.
- **the reel** — `fall-2026/weiting-w/final-project-film/`, inside the course repository. This
  is what gets submitted. The toolkit is pointed at it from outside.

## 1b. One required patch to the toolkit

`ClaudeTitleOutro.tsx` hardcodes the instructor's handle as a module constant — it takes no
handle prop, so nothing in a beat sheet can change it, and `bookend_check.py` cannot see it
because that gate only compares fields inside the JSON. The assignment forbids using the
instructor's credit line, so the constant has to change:

```bash
cd ~/dev/brutalist.art
sed -i '' "s/^const HANDLE = '@NikBearBrown';/const HANDLE = '@WeitingWang0704';/" \
  runtime/remotion/src/scenes/ClaudeTitleOutro.tsx
grep -n "^const HANDLE" runtime/remotion/src/scenes/ClaudeTitleOutro.tsx
```

The component's own header says it is for "claude-liam / @NikBearBrown reels ONLY", and this
reel is neither, but the toolkit ships no other outro card. The patch stays in the external
checkout; nothing of the toolkit is committed to the course repository. See `FRICTIONAL.md`.

## 2. Install it

```bash

```

This installs the Python dependencies and the Remotion node modules, then downloads the Kokoro

row the film needs must say READY. Re-check any time with `./setup` (or `./art doctor`).

## 4. Audio — the clock

Durations in the committed `beat_sheet.json` are estimates from word count. The real clock is
measured audio, so this step rewrites them.

```bash
REEL=~/path/to/fall-2026/weiting-w/final-project-film
cd ~/dev/brutalist.art
python3 runtime/scripts/generate_audio_kokoro.py "$REEL"
```

Then, per the skill: pad `BOUT` with a 1.0 s silent tail and write the `ffprobe` durations back
into `actual_duration_s`. **After this, do not re-run `make_sheet.py`** — it would overwrite the
measured durations with estimates again. To change a line of narration later, edit it in
`make_sheet.py`, re-run it, and regenerate that one beat's audio with
`generate_audio_kokoro.py "$REEL" --only B0X`; a full run re-voices every beat and silently
drops BOUT's pad.

Whisper-check the first beat, and check "AI" in `BIDEA` and in the Your Turn prompt — the skill
records that Kokoro mangles some acronyms.

## 5. Stills before any 4K render

```bash
cd "$REEL"
manim -ql -s scenes.py B00_Project     # … and each of the other 13 classes
```

Look at the frames. A gate tells you a frame is legal, not that it is the picture you meant —
label collisions in particular pass every gate here and are only visible in the frame.

Text size: every label is 42. GATE T failed a serif run 1 px under its 41 px floor on the
author's week-01 film, and EB Garamond renders shorter than sans at the same nominal size, so
nothing in this reel sits near the floor. Raising the labels to 42 re-introduced two collisions
("compilerconsole" in B02, "false alarmscaught" in B07B) that the layout audit did not flag; the
columns were widened to fix them.

Shape matters too, and not only for type. GATE T decides what is text from colour and geometry
alone: any ink or terracotta blob at least ~34 px tall, 1.5 to 15 times wider than tall and at
least 4% filled is treated as a text run, then checked for WCAG contrast and for overlap with
other "runs". Two drawings in this film tripped that — the arm in B04 and the glow in B08/B08B —
and both are now drawn taller than they are wide, which is the one property the checker uses to
rule a blob out. Keep them that way if you redraw them. See `FRICTIONAL.md`, 2026-10-14.

```bash
BA=~/dev/brutalist.art
python3 "$BA/runtime/scripts/bookend_check.py" "$REEL"

# per scene — Gate A must run in a folder holding ONLY scenes.py, which is what it sees
mkdir -p /tmp/gateA && cp scenes.py /tmp/gateA/ && cd /tmp/gateA
for C in B00_Project B01_StringReach B02_SilentPass B02B_WhatWarns B03_HalfRead \
         B04_WritesIn B04B_ByHand B05_Checklist B05B_ReadOnly B06_Fixture \
         B07_FalseAlarm B07B_TwoNumbers B08_HaveTray B08B_NewTray; do
  python3 "$BA/runtime/qc/static_scene_check.py" scenes.py --class "$C" --quiet
done

cd "$REEL"   # Gate W and Gate B run against the reel, where beat_sheet.json sits
for C in …same list…; do
  python3 "$BA/runtime/qc/wcag_margin_check.py"   scenes.py --class "$C"
  python3 "$BA/runtime/qc/manim_layout_audit.py"  scenes.py --class "$C" --curve-strict
done
```

All of these passed on 2026-10-13 before any audio existed.

One extra check of our own, because nothing in the toolkit catches it: `iso_kit.py`'s
`until(phrase)` waits for a spoken phrase by finding it in that beat's narration, and returns
silently if the phrase is not there — the scene then plays out of sync with the voice and no
gate notices. Re-run this whenever the narration changes:

```bash
python3 - <<'EOF'
import json, re
sheet = {b['beat_id']: b['narration_text'] for b in json.load(open('beat_sheet.json'))['beats']}
src = open('scenes.py').read()
bad = [(bid, ph) for bid, _, body in
       re.findall(r'^class (B[0-9A-Z]+)_(\w+)\(Scene\):(.*?)(?=^class |\Z)', src, re.S | re.M)
       for ph in re.findall(r'until\(self,\s*"([^"]+)"', body)
       if ph not in sheet.get(bid, '')]
print('broken until() calls:', bad or 'none')
EOF
```

## 7. Render

```bash
cd ~/dev/brutalist.art
./art run   "$REEL" --height 2160     # Gates F, L, A, W, B, V — renders every beat
./art todo  "$REEL"                   # anything still unfilled
./art final "$REEL" --height 2160     # Gate T, then the clean master
```

**`art final` does not render.** It assembles the beats `art run` has already written into
`manim/` and `media/`. Running `final` on a cleared cache produces a reel of slate placeholders,
which the clean master rejects by design. Always `run` first, then `final`. (This cost time on
the author's week-01 film; see that reel's `FRICTIONAL.md`.)

**Two different files, and they are easy to confuse.** `art run` writes a *review* cut named
`<slug>-slate.mp4`, with a debug label burned into the corner of every beat. The clean master is
written separately by `art final` into `renders/<slug>.mp4`, with no label. The master is the one
that ships; rename it to `Wang_Weiting_INFO7375_FinalProjectFilm.mp4` in the reel folder.

`art run` only renders scenes whose `manim/<BID>.mp4` is missing. After editing a scene, move
its old clip and the stale Manim cache to `_superseded/` and run again, or the old clip is kept.

Check the master: 3840×2160, the silent tail is there, and the sha is recorded. For reference,
the author's week-01 4K master came to 16 MB for 198 s — comfortably inside GitHub's 100 MB
per-file limit, so no Git LFS is needed.

## The deviations from the toolkit's defaults, and why

All four come from the assignment's rule to narrate as oneself and not use the instructor's
name, persona or credit line. They are set in `make_sheet.py`; `FRICTIONAL.md` records them.

1. `BIDEA` opens in the author's own voice, not "Hallo. This is Liam, in for Bear."
2. `metadata.persona` and `metadata.channel` name the author.
3. `metadata.channel_title` and the `BOUT` handle are the author's; `subline` is empty.
   `bookend_check.py` compares the outro handle against `channel_title`, so this passes — and
   `OUTRO-LOCK.md` scopes itself to `claude-liam-*` slugs, which this is not.
4. Voice is Kokoro `af_bella`, not the default `am_onyx` ("Liam").
