# BiteCheck: a pitch film (v2)

**Omkar Salian** · INFO 7375 (Prompt Engineering for Generative AI), Fall 2026 · Final Project Pitch Film

- **Working title:** BiteCheck: do Claude's API tests actually catch bugs?
- **Target role:** new-grad Software Engineer / AI Engineer
- **Runtime:** 3:52 (231.5 s), 1920×1080, 24 fps, synthetic first-person narration (Kokoro `am_michael`, free and local) of a script Claude drafted and I approved
- **Film:** `bitecheck-pitch.mp4` (sha256 `dc8802e3d6342295cf9c24943c0860d4090d8da42dea6855daed6b38c9e7d3ff`).
  It is in the Canvas zip. The course repo's `.gitignore` keeps `*.mp4` out of Git, so the GitHub folder has everything else and rebuilds the same film from `scenes.py` + `beat_sheet.json`.

**Who:** Omkar Salian, MS Software Engineering student at Northeastern, building it alone with Claude Code as his coding assistant.

**In plain words:** you only know a smoke alarm works if you blow smoke at it. Tests are software's alarms, and BiteCheck is the smoke: it breaks one business rule on purpose and checks which tests go off.

**The pitch in one sentence:** BiteCheck will be a Claude Code workflow that writes API regression tests for my loan-origination demo and then checks that each test fails when a business rule is broken on purpose, with a log of every test Claude got wrong.

**What exists today (2026-10-22):** the loan-origination API (local, ran on synthetic applicants), a StrykerJS run on its rules (92 mutants, none on the ₹15,000 limit), income-rule unit tests and a mutant checker written by Claude Code (2026-10-21), two mutants (Claude's `<`→`<=` and my 15,000 → 1,500, 2026-10-22), a first GitHub Actions run in my private repo (2026-10-22: all passed, 2 killed), this brief and this film. **Everything else is proposed.** Every beat carries an on-screen tag: WHO, ANALOGY, REAL, PROPOSED, SELF-REPORT or STATUS.

## Rebuild
Needs macOS/Linux, Python 3.12, ffmpeg, Node 20+, and [brutalist.art](https://github.com/nikbearbrown/brutalist.art) at `b21f625` as a sibling folder. Full commands are in `BUILD-PROMPT.md`. In short:

```bash
python3 make_sheet.py
python3 ../brutalist.art/runtime/scripts/generate_audio_kokoro.py "$PWD"
../brutalist.art/art run   "$PWD" --height 1080
../brutalist.art/art final "$PWD" --height 1080 --out "$PWD/final"
```
