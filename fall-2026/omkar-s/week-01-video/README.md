# Week 1 video: Subtract the Max

**Omkar Salian** · INFO 7375 (Prompt Engineering for Generative AI), Fall 2026 · Week 1

**Concept:** why subtracting the maximum score changes the intermediate weights in softmax but not the distribution (Chapter 1, Part 2, "The subtraction that changes nothing important").

**Why this one:** it is small enough to explain completely in three minutes, and every claim can be shown with numbers the course code actually prints, including a real failure (an `OverflowError`) and a real limit (underflow to exactly `0.0`).

**Runtime:** 3:14 (194.1 s), 1920×1080, 24 fps, synthetic narration (Kokoro `af_bella`).

## What's in the video

| Beat | Time | What it shows |
|---|---|---|
| B00 | 0:00 | The real `peak = max(logits)` line in the course's `probabilities()` |
| B01 | 0:17 | Plain softmax on [1, 2, 3]: weights 2.718282 / 7.389056 / 20.085537, total 30.192875, probabilities 0.0900 / 0.2447 / 0.6652 |
| B02 | 0:37 | Shifted: [−2, −1, 0] → 0.135335 / 0.367879 / 1.000000, total 1.503215, same probabilities |
| B03 | 0:57 | Why: every weight *and* the total are divided by e³ = 20.085537, so the factor cancels |
| B04 | 1:18 | [1001, 1002, 1003]: the naive route raises `OverflowError`; the shifted route gives identical probabilities (`A == B exactly: True`) |
| B05 | 1:43 | The lesson's own test: [1000, 1000] → [0.5, 0.5], `test_02 … ok` |
| B06 | 2:01 | Honest detail: the two routes agree up to floating-point rounding (they differ in the 16th significant digit) |
| B07 | 2:19 | **What this does not establish:** [0, −1000] returns exactly `0.0` for a positive probability (exp(−1000) = 5.1e−435 < 5e−324). Max-subtraction prevents overflow, not underflow. |
| B08 | 2:52 | Recap and sources/disclosure card |

## Rebuild

Needs macOS/Linux, Python 3.12 venv, ffmpeg, Node 20+, the [brutalist.art](https://github.com/nikbearbrown/brutalist.art) toolkit at `6a8380a`, and this course repo at `e6c6c49`. Full commands are in `BUILD-PROMPT.md`. In short:

```bash
python3 evidence/max_shift_evidence.py                        # check the numbers still match evidence/
python3 ../brutalist.art/runtime/scripts/generate_audio_kokoro.py "$PWD"   # audio is the clock
# render each scene in scenes.py at 1920x1080 into manim/<BEAT>.mp4 (loop in BUILD-PROMPT.md)
../brutalist.art/art run   "$PWD" --height 1080               # review cut + visual QC
../brutalist.art/art final "$PWD" --height 1080 --out "$PWD/final"
```

Build caches (`mp3/`, `manim/`, `clips/`, `media/`, `_qc/`) are regenerated by these commands and are not committed.
